Set Programım · Destek

Set programındaki sahnelerin, gün gün.
Bir sorun mu var ya da programın okunmadı mı? Yaz: creator@derindunyaapp.com
Okunmayan bir programı ekte gönderirsen okuyucuyu o şablona göre geliştirebiliriz.

Nasıl kullanılır?

  1. Alttaki + düğmesine bas, karakter adını yaz.
  2. Haftalık ya da günlük set programı PDF'ini seç.
  3. Sahnelerin gün gün dizilir. Sahneye dokununca özeti, kostüm ve notları açılır.
  4. Sahneyi sola kaydır: çekildi. Sağa kaydır: çekilmedi. Çift dokun: "şimdi çekiliyor".

Denemek için ilk açılışta Örnek programla dene düğmesine basabilirsin.

Sık sorulanlar

  • Hangi programlar okunuyor? Yazı içeren (taranmamış) PDF set programları: SAHNE · ZAMAN · MEKAN · OYUNCULAR · ÖZET sütunlu haftalık ve günlük programlar.
  • İnternet gerekir mi? Hayır, program cihazında okunur.
  • Verilerim nerede? Yalnızca telefonunda. Ayrıntı: Gizlilik Politikası.
  • Adımın yanında "?" var. Programda adının yanında soru işareti varsa uygulama sahneyi "teyit et" diye işaretler.
